# Ping-Me 📨

**Ping-Me** is a real-time chat application built using the **MERN Stack** (MongoDB, Express.js, React.js, Node.js) with **Socket.io** for real-time bi-directional communication. The app supports user authentication, and instant messaging between users.

---

## 🛠️ Features

- 🔐 **User Authentication**
  - Sign Up / Sign In functionality with JWT token
- 💬 **Real-time Messaging**
  - Powered by Socket.io
- 🟢 **Online User Indicator**
- 🧠 **Smart Conversations**
  - Displays past messages when a chat is opened
- 🔍 **Search Users**
- 🚪 **Logout Functionality**
- 💻 **Modern UI**
  - Built with TailwindCSS
